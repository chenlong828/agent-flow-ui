# REQ-0024 发起运行的工作区路径历史

| 字段 | 内容 |
|---|---|
| ID | `REQ-0024` |
| 类型 | `feature` |
| 场景叙述 | 操作者在运行实例页发起运行，选定已绑定执行节点的 Harness 后，可从工作区路径输入框右侧的下拉框直接选择该执行节点最近使用过的路径（最多 10 条），也可继续手输新路径；发起成功后本次路径自动置顶记入历史；可在列表项右侧用小叉删除不再需要的路径。 |
| 价值 | 工作区路径是执行节点上的绝对路径，长且容易输错；每次发起运行都要重新填写或改写上一次的路径。按执行节点记住最近 10 条，让高频工作区切换一次点选完成，同时避免把某台执行节点的路径混到另一台执行节点上。 |
| 非目标 | 不做路径存在性/可写校验（前端无法访问执行节点文件系统）；不做跨标签页实时同步、云同步或按账号同步；不改后端 `workspacePath` 入参与「同 `clientId` + 路径复用」规则；不记录非绝对路径；不把历史写入 B4 业务数据；不新增独立页面或管理入口。 |
| 约束 | 只存 localStorage `df-launch-workspace-paths`（`{v:1,byClient:{<clientId>:string[]}}`）；按执行节点 `clientId` 隔离、每节点最多 10 条、最近使用置顶、同路径去重；只在发起运行成功后写入；损坏 JSON、版本不符、非 `/` 开头条目按空历史或过滤处理；切换 Harness 只切换下拉列表，不自动改写输入框；不新增运行时依赖。 |
| 影响场景 | `SCN-0004`（扩展 T7 正例与 T8 反例） |
| 澄清记录 | 2026-11-18 用户确认：路径历史与 Harness 执行器绑定，一个执行器最多 10 条；按 `clientId` 隔离；交互为「输入框 + 下拉选择」，保留手输；发起成功后写入；下拉列表项右侧提供小叉删除。 |
| 状态 | `delivered`（2026-11-18；`SCN-0004` 8/8） |
