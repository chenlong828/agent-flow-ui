# REQ-0022 运行节点文件与执行会话观测

| 字段 | 内容 |
|---|---|
| ID | `REQ-0022` |
| 类型 | `feature` |
| 场景叙述 | 运行观察者在运行详情里双击一个执行节点，或从页头打开「任务文件」，能只读浏览本次 run 的 task-space/workspace 文件；在节点弹层里查看该节点本轮执行会话的状态、事件与实时富事件流，并下载 raw 会话归档。 |
| 价值 | 当前只能看到节点结论、消息和 gzip 会话日志下载；任务文件与执行会话过程不可见，复盘「为什么失败、中间做了什么、产物在哪」必须回到执行机。接入 API-48–53 后，文件审查与会话追踪在同一个 90% 弹层内完成，不用离开运行详情。 |
| 非目标 | 不做文件编辑/上传/删除、终端、二进制预览、运行后归档浏览、attempt 产品端点；UI 不直连 3100/client；不改运行状态机、人工确认与终止行为；不引入 Prism 等新运行时依赖。 |
| 约束 | 只经同源 BFF 访问 `API-48`–`API-53`；UI 不展示 `sessionId`/`attemptId`；文件只读并以 `truncated`/`reason` 原样展示；SSE 用 `EventSource`，关闭弹层/切 Tab/切轮次必须关闭；BFF 流式路径不缓冲、无总超时；`CMP-run-data` 是唯一读入口。 |
| 影响场景 | `SCN-0021`（新建；同一页面但新增独立操作与价值，不复用 `SCN-0004` 的断言） |
| 澄清记录 | 2026-11-18 用户确认：入口为节点弹层 + 详情页头部「任务文件」；Tab 为 概要 / 文件 / 执行会话 / 会话日志；代码预览先纯文本 + 语言标签，不引入 Prism；因页面内新增了独立操作与价值，新建独立场景而非扩展 `SCN-0004`。 |
| 状态 | `delivered`（2026-11-18；`SCN-0021` 6/6；BFF 流式 16/16；真实 run 文件/会话/raw 走查通过） |
