# REQ-0020 节点详情双击 90% 弹层

| 字段 | 内容 |
|---|---|
| ID | `REQ-0020` |
| 类型 | `feature` |
| 场景叙述 | 流程研发者在工作流编辑器单击节点/阶段/连线只切换选中高亮，双击才打开属性弹层；运行观察者在运行实例详情单击节点只选中，双击才打开节点详情。弹层宽高各为界面 90%，头部与底部固定，内容超出时在弹层内部滚动；运行实例的节点消息直接在弹层内阅读，不再需要二次「全屏」。 |
| 价值 | 右侧抽屉/常驻面板长期挤占画布宽度，大屏下详情展示面积不足；节点消息再套一层整屏浮层属于重复放大。统一为双击打开的大弹层后，画布恢复全宽，详情获得足够展示面积，两个页面的查看交互一致。 |
| 非目标 | 不改运行/工作流的数据结构、API 与运行控制能力；不改其他页面继续使用的右侧抽屉；不改画布拓扑编辑、连线、保存与校验规则；不做移动端适配。 |
| 约束 | 无新增运行时依赖；弹层统一走 `DF.modal.open({ size: 'screen' })`，页面不重复计算尺寸；弹层内容超高时由弹层主体滚动，窗口 resize 时重算；Esc/遮罩/右上 × 可关闭；工作流编辑器双击节点/阶段/连线均可打开，运行实例双击节点打开；节点消息与确认说明不再提供二次全屏。 |
| 影响场景 | `SCN-0019`（工作流编辑器）、`SCN-0004`（运行实例） |
| 澄清记录 | 2026-11-17 用户提出：工作流编辑器与运行实例的查看不再使用右侧抽屉，改为双击节点/元素后弹层展示；弹层为界面 90% 高度、90% 宽度，超出后内部滚动。同日补充：节点消息已在大弹层展示，去掉二次「全屏」入口。实现落 `history/works/2026-11-17-node-detail-modal/`，两场景复跑通过。 |
| 状态 | `delivered`（2026-11-17；`SCN-0019` 24/24、`SCN-0004` 5/5） |
