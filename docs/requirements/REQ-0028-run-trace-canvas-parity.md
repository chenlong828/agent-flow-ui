# REQ-0028 运行轨迹图与编辑器画布同源

| 字段 | 内容 |
|---|---|
| ID | `REQ-0028` |
| 类型 | `quality` |
| 场景叙述 | 运行观察者打开运行详情时，轨迹图的连线与保存时编辑器里看到的一致：起止锚点沿用 `node.layout.inSide/outSide`、同节点进出锚点自动错开、seq 边有箭头、rollback 边是紫色虚线与「↺ 回退」标签；整张图按 `graph.viewport` 的缩放与平移呈现。连线不再从节点右边框固定出、绕到左边框进，不再横穿画布遮挡节点。 |
| 价值 | 执行页与编辑器画的是两张不同的图：同一节点在编辑器里从下边框出发，在运行页却从右边框绕一圈，线还会穿过节点与状态标签，用户无法对照「设计连线」与「执行到哪」，容易误判为快照或数据错误；运行图不按保存视口呈现时，两处位置也完全不同，排障时来回切换要重新找节点。 |
| 非目标 | 不改后端 API、不改 `RunDetail.graph` 冻结快照语义（运行仍展示启动时的图）、不做运行页的缩放/平移控件、不做运行期编辑、不改工作流编辑器的交互与连线输出。 |
| 约束 | 编辑器现有连线路径必须逐字不变（用基准 `d` 锁定）；共享几何层只做纯计算，不碰 DOM/网络/状态；`inSide/outSide` 只影响贴边，不影响边 `from/to/kind`；同一节点 seq 边仍最多一进一出；非法锚点值按自动选边处理，不产生 `NaN` 路径；图缺失时保留「无可用图快照」占位。 |
| 影响场景 | `SCN-0023`（新建，T1–T4 验收）；`SCN-0019`（回归：编辑器连线、箭头与选边断言保持通过，不新增断言） |
| 澄清记录 | 2026-11-19 用户报告「执行过程中的流程图与保存时不一样，主要是连线没有同步」，确认走方案 B：抽共享几何层 + 运行页套用保存视口，保留 `RunDetail.graph` 冻结快照。用户提供的 runId `01a1f407-d79c-741c-ad10-584c66faca23` 在当前后端返回 404（`run_not_found`，运行列表 39 条中无此 ID），未做单例核对；按通用问题修复并以夹具场景验收。 |
| 状态 | `delivered`（2026-11-19；`SCN-0023` 4/4、`SCN-0019` 24/24 回归） |
