# REQ-0001 顶栏用户区显示与下拉菜单

| 字段 | 内容 |
|---|---|
| ID | `REQ-0001` |
| 类型 | `feature` |
| 场景叙述 | 在任意页面，用户点击右上角用户区，看到「陈龙」与下拉菜单；可进入个人 Key 管理，或退出登录（原型静态，仅确认与反馈）。 |
| 价值 | 用户区是全局唯一身份入口；没有它，顶栏只有静态文本，Key 管理与退出登录无入口。 |
| 非目标 | 不做真实登录态与鉴权；不做个人资料页；不改 mock 数据里的「陈明」（模拟人物，非登录名）。 |
| 约束 | 纯前端静态原型；不新增依赖；12 页行为一致；桌面视口优先。 |
| 影响场景 | `SCN-0001`（`design/scenarios/shell/topbar/user-menu/scenario.md`） |
| 澄清记录 | 2026-10-13 自 OQ-7 领取：显示名改「陈龙」，菜单含 Key 管理 / 退出登录，登出静态。<br>2026-10-13 收口于 `2026-10-13-user-menu`，引擎层 45 通过 / 0 失败。<br>2026-10-23 四态迁移五态：OQ-7 退役，转本卡；Safari 人工走查仍未完成，记为发布确认项。 |
| 状态 | `delivered` |
