# REQ-0015 Skill 包形态：正文 + 脚本/参考附件 + 草稿保存

| 字段 | 内容 |
|---|---|
| ID | `REQ-0015` |
| 类型 | `feature` |
| 场景叙述 | Skill 维护者从列表进入专门的 Skill 页，查看 `SKILL.md` 正文与附件清单；点「编辑」建立草稿，修改元数据与正文、上传或整理 `scripts/`、`references/` 下的文件；保存后整包生效，并可下载 `<name>-<version>.zip` 交给运行时；新建也走同一草稿流程。 |
| 价值 | 没有它，Skill 只能存五章文本与假引用：脚本与二进制无处安放、每次保存都会清空引用、正文写不了代码块与表格，Skill 无法被真正执行。 |
| 非目标 | 不做图片附件与图片预览；不做单文件下载、在线执行、版本历史/回滚、多人协作与鉴权；不维护第二套编辑器（只保留一个 7.7.0 包）；不改 Skill 列表、启停、删除、引用保护语义。 |
| 约束 | 正文上限由后端固定为 `SKILL.md` 16 KiB（含 frontmatter），更长的内容放 `references/` 渐进披露；附件只允许 `scripts/`、`references/` 两个根；附件不接收图片；保存必须走草稿并带 `If-Match`；读写一律以后端 v1 契约为准；依赖体积为观测阈值，不阻断。 |
| 影响场景 | `SCN-0016`（草稿编辑与保存，新建）；`SCN-0017`（整包下载，新建）；`SCN-0005`、`SCN-0014`、`SCN-0015` 需按新流程重写；原 v2 契约场景随之废弃。 |
| 澄清记录 | 2026-10-29：以后端 v1 契约为唯一口径；16 KiB 是刻意设计，超出内容走 `references/`；附件不含图片；脚本作为附件保留以便执行；不做迁移（Skill 未实际使用）。 |
| 状态 | `accepted` |
