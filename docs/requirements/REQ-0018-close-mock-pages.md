# REQ-0018 MOCK 演示页临时关闭与演示模式

| 字段 | 内容 |
|---|---|
| ID | `REQ-0018` |
| 类型 | `feature` |
| 场景叙述 | 用户进入前台时，默认导航只展示已接入真实后端的页面；直达效能看板、工作区列表/详情、个人 Key 管理四个 MOCK 页时，看到「该页面由演示数据驱动，已临时关闭」占位与返回入口；评审或演示需要查看时，通过地址上的 `?demo=1` 在本标签页恢复这些页面与导航入口，`?demo=0` 退出。 |
| 价值 | MOCK 页与已 live 的页面混在同一导航里，容易被误认为真实能力；临时关闭既降低误解，又保留随时演示的入口，且不删除页面、数据与规格。 |
| 非目标 | 不删除 MOCK 集合、页面代码与文档；不改变三个页面的业务行为（字段、分页、交互）；不做权限/环境级开关或后端开关；不持久化到 localStorage，不跨标签页继承；不把分页需求并入本次（分页另行提案，暂缓）。 |
| 约束 | 无新增运行时依赖；关闭状态不执行页面主体、不发页面数据请求；直达必须有占位说明与演示入口；演示模式只由 URL 参数开关（`?demo=1` / `?demo=0`），本标签页内保持；不改变 SCN-0009/0010/0011 的业务断言（以 `?demo=1` 执行）；用户区「个人 Key 管理」入口保留。 |
| 影响场景 | `SCN-0020`（新建）；`SCN-0009` / `SCN-0010` / `SCN-0011`（入口加 `?demo=1`，断言不变）；`SCN-0001`（用户区菜单保留） |
| 澄清记录 | 2026-11-12 用户指示：先临时关闭 MOCK 页（有需要再展示），分页暂时不增加、以后再做。范围=效能看板、工作区列表+详情、个人 Key 管理；方式=导航隐藏 + 直达占位 + `?demo=1` 放行；本轮直接实现。分页评估另见 `works/2026-11-12-list-pagination-proposal/`。 |
| 状态 | `delivered`（2026-11-12；`SCN-0020` verified，M1 全量 50/50） |
