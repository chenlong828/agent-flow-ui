# REQ-0021 运行节点多轮历史查看

| 字段 | 内容 |
|---|---|
| ID | `REQ-0021` |
| 类型 | `feature` |
| 场景叙述 | 运行观察者打开运行实例详情，双击一个已经重新进入或被打回的节点，在弹层中通过轮次 Tab 查看最新一轮和之前各轮的执行记录；每一轮分别显示状态、消息、判定结论、错误与会话日志。被打回的评审节点仍可打开并看到当时的驳回结论与内容。 |
| 价值 | 只显示最新一轮会丢掉回退链路：打回原因、上一轮产出和评审结论都看不到，运行观察者无法复盘为什么回退、改了什么。保留每一轮后，「重新进入 / 打回重跑」的过程可追溯，人工确认与日志下载也能对到具体轮次。 |
| 非目标 | 不改后端 `RunDetail` / `RunNodeView` 数据结构与运行状态机；不提供节点重试/从节点重跑（后端未提供）；不展示同一轮内多次 `attempt` 的细分（按 `visit` 轮次聚合）；不在画布上展开历史轮次。 |
| 约束 | 数据源为 `GET /runs/{id}` 的 `run.nodes`，按 `nodeId + visit` 聚合；轮次倒序排列，最新一轮在左；默认打开最新轮，轮询到新轮次时若停留在最新则自动跟随，停留在历史则保持；历史轮次只读，不出现人工确认入口；会话日志按 `visit` 查询参数下载；无新增依赖。 |
| 影响场景 | `SCN-0004`（`design/scenarios/operations/instances/control-instance/scenario.md`） |
| 澄清记录 | 2026-11-17 用户指出：弹层只显示最新信息，节点重新进入或转回后看不到上一轮；希望打回到节点的内容、打回后之前审核节点的内容都能显示，并用 Tab 展示最新版与历史轮。实现按 `run.nodes` 的多 `visit` 记录展开轮次 Tab，落 `history/works/2026-11-17-run-node-history/`。 |
| 状态 | `delivered`（2026-11-17；`SCN-0004` 6/6） |
