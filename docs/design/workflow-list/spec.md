# 工作流列表

> 导航：流程研发 / 工作流　|　形态：列表页（卡片/表格双视图）　|　前置：`design/ui-shell.md`

## 1 页面定位

不同类型工作流任务的统一入口：浏览、检索、发起运行，并进入编辑器创建/修改。

## 3 元素明细

| 区域 | 元素 | 类型 | 说明与交互 |
|---|---|---|---|
| 页头 | 新建工作流 | 主按钮 | 打开新建弹窗 |
| 筛选 | 类型 Tab | Tab | 全部 / 研发主流程 / 专项子流程 / 批量审视任务（R2 确认的分类维度） |
| 筛选 | 搜索框 | 输入 | 按名称模糊匹配 |
| 统计条 | 汇总指标 | 文字 | 总数 / 运行中 / 等待人工确认 / 本周新增运行；点击「等待人工确认」跳实例列表对应筛选 |
| 视图切换 | 卡片/表格 | 分段控件 | 记忆选择（localStorage） |
| 卡片 | 名称 + 类型标签 | 文字 | 类型标签按类型着色 |
| 卡片 | 版本 + 发布状态 | 文字+标签 | v1.2 · 已发布/草稿（R4：仅版本号+标记，无版本历史） |
| 卡片 | 节点数/阶段数 | 文字 | 如「12 节点 · 4 阶段」 |
| 卡片 | 最近运行状态 | 状态点+文字 | 成功/失败/运行中/从未运行；点击跳实例列表（按该工作流过滤） |
| 卡片 | 操作 | 按钮组 | 编辑（进编辑器）、运行（发起运行弹窗）、更多▾（复制、导出 DSL、删除） |
| 表格 | 列 | 表格 | 名称/类型/版本/节点数/最近运行/更新人/更新时间/操作 |

## 4 新建工作流弹窗

| 字段 | 控件 | 必填 | 说明 |
|---|---|---|---|
| 名称 | 输入框 | ✓ | — |
| 类型 | 单选（研发主流程/专项子流程/批量审视任务） | ✓ | 默认专项子流程 |
| 描述 | 多行输入 | — | 一句话用途 |
| 从模板创建 | 模板卡片单选 | ✓ | 空白流程 + 4 个示例模板（研发四阶段主流程/需求分析子流程/批量代码审视/每日构建复验），选中显示缩略示意 |

提交后跳转编辑器（草稿态）。

## 5 关键交互流程

列表 → 编辑（编辑器）｜运行（发起运行弹窗，同实例页 §2.3）｜复制（生成「副本」草稿）｜删除（二次确认弹窗，含「有 N 个实例引用」警示，原型允许强制删除）｜导出 DSL（下载 JSON 文件）。

## 6 状态与空态

- 类型 Tab 无数据：空态「该类型暂无工作流，新建或从模板创建」
- 搜索无结果：空态 + 清除搜索按钮

## 7 模拟数据依赖

`MOCK.workflows[]`：6 个模板（名称/类型/版本/发布状态/节点数/阶段数/最近运行/更新人/更新时间/DSL 摘要）。
