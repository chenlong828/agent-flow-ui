# 工作流编辑器

> 导航：流程研发 / 工作流 → 编辑器（独立二级页）　|　形态：拖拽画布　|　前置：`design/components/ui-shell/spec.md`、`design/components/workflow-list/spec.md`

## 0 模块卡

> 追溯：`REQ-0003` / `SCN-0003`（designed，未 verified）。

- 状态：active
- 单元 / 层：组件 / L2 页面组件
- 业务价值：为工作流的研发编排者提供「节点 + 有向边 + 收敛配置」的可视编辑与校验；没有它，工作流只能停留在列表里的静态条目，评审回退、并行网关与上下文收敛无处配置，也无法产出可运行的 DSL。
- 负责 / 不负责：负责画布编辑（拖入节点、连线、缩放、属性抽屉）、流程校验、DSL 只读预览/复制/导出，以及编辑态「保存 / 发布」对 `MOCK.workflows` 的内存态改写；不负责工作流列表与检索（`CMP-workflow-list`）、运行实例的发起与生命周期（`CMP-instances`）、专家 / Skill / Harness / 工具等资产本身（`CMP-experts` / `CMP-skills` / `CMP-harnesses` / `CMP-tools`）。
- 数据所有权：读 `MOCK.workflows`、`MOCK.experts`、`MOCK.skills`、`MOCK.harnesses`、`MOCK.tools`、`MOCK.workspaces`、`MOCK.knowledgeTree`；写 `MOCK.workflows`（编辑态 graph、name / ver / published / nodeCount / stageCount，仅内存态，刷新复位）；存在第二写入口——`CMP-workflow-list` 同样写 `MOCK.workflows`（新建 / 复制 / 删除），按 R8 原型豁免登记，接真实后端时按数据服务重切；画布视图状态（zoom / sel / tab / dslFmt / dirty）只在内存，不落 localStorage。
- 公开契约：页面入口 `pages/workflow-editor.html?id=<workflowId>`（缺 id 回落 `MOCK.workflows[0]`）；操作 `CMP-workflow-editor#open` / `#drag-node` / `#connect-edge` / `#inspector` / `#validate` / `#exportDsl`；不变量：同一评审节点至多一条回退边且目标必须是它的前序节点（重复连线需确认替换），开始/专家/评审/人工确认/fan-in/结束节点至多一条向前出边；孤立节点、评审缺回退目标、专家节点缺专家绑定、fan-out 缺清单来源由 `#validate` 拦截（孤立节点记 warn，其余为 err，err 未清零不得发布）；所有视口↔图形坐标换算统一走 `toGraph` / `clientDelta`，缩放只在 `paint` 中以 `transform: scale` 施加。
- 依赖：`DF`（`window.DF`：外壳、弹窗、表格、`zoomK` / `zoomOnFixed`）、`MOCK`（`window.MOCK`）；不依赖其他页面组件（不复用 `CMP-workflow-list` 的 JS 逻辑）。
- 变化轴：节点类型集合与其校验规则——新增一种节点类型须同步改左侧面板、`addNode`、属性抽屉分派、`validateGraph` 与 DSL `payload` 五处。
- 验证入口：`npm start` + `/pages/workflow-editor.html?id=w1`；`node tools/smoke-test.js`；SCN-0003（designed，3 正 1 反测试方案已登记；runner 待补）。
- 预算：源码 + 规格 + 测试约 70 KB（上限 120k token，本组件远低于上限）。
- 单独运行：`npm start` → `http://localhost:3000/pages/workflow-editor.html?id=w1`。
- 删除测试：删除后「工作流可视化编排」能力整体消失（列表只能新建/复制，不能改结构、校验或导出 DSL），复杂度从本组件集中移到未来的编排服务，不留在其他页面。
- 已知偏差：M1 追溯已补（REQ-0003/SCN-0003），场景 designed、未 verified；素材为 `MOCK` 夹具，刷新即复位；仅结构冒烟，拖拽与坐标类断言在 jsdom 不可证，后续如需行为变更应补引擎层场景（如坐标换算与回退边唯一性断言）。

## 1 页面定位

核心编排界面：以拖拽画布维护「节点 + 有向边」结构，节点绑定专家并配置上下文与收敛约束；支持评审回退边与并行网关；提供只读 DSL 视图。

## 3 顶栏

| 元素 | 说明 |
|---|---|
| 返回 | 回列表（未保存更改提示确认） |
| 名称 | 内联编辑；旁显版本号 + 发布状态标签（R4：仅版本号+草稿/已发布标记） |
| 画布 / DSL Tab | **顶栏平级切换（R4）**：DSL 视图为只读 JSON/YAML 预览 + 格式切换 + 复制 + 导出 |
| 校验 | 下拉面板列出校验错误，点击定位到节点/边 |
| 保存 / 发布 | 保存草稿；发布需校验通过（发布后版本号 +0.1） |
| 运行 | 已发布可用；打开发起运行弹窗（同 `design/components/instances/spec.md` §2.3） |

## 4 左侧节点面板（拖拽源）

| 分组 | 节点 | 说明 |
|---|---|---|
| 基础 | 开始 / 结束 / 阶段分组 | 阶段分组为容器框，可拖入子节点 |
| 执行 | 专家执行节点 | 主角色，默认色蓝 |
| 控制 | 评审/校验节点、人工确认节点 | 评审=紫描边、人工=橙描边 |
| 并行 | fan-out / fan-in 网关 | 菱形/漏斗图形标识 |

## 5 画布

- 网格背景 + 缩放（−/百分比/+、适应画布）；节点拖拽吸附网格；单选节点/边（原型不做框选批量）
- **节点卡片**：类型图标、名称、专家标签（头像色点+名）、状态色边框；左侧入端口、右侧出端口；评审节点额外下方「回退端口」
- **边渲染**：顺序边=实线箭头；回退边=紫色虚线弧（带「回退」标签）；fan-out→子任务→fan-in 用双线示意并行带
- **连线交互**：从出端口拖至目标节点=顺序边（专家/人工/开始节点仅 1 条出边，重复连线提示替换）；从评审「回退端口」拖至**任意前序节点**=回退边（唯一，重新连线需确认替换）
- 边删除：点击选中 + Delete 键或悬浮 × 按钮

## 6 属性抽屉（按节点类型）

### 6.1 公共
名称（必填）、说明。

### 6.2 专家执行节点
| 配置 | 控件 | 说明 |
|---|---|---|
| 绑定专家 | 下拉搜索 + 摘要卡 | 显示角色定位与 Skill 数 |
| Skill 组合 | 继承开关 + chips | 默认继承专家；可增删、排序（拖拽） |
| Harness 分配 | 单选：按标签自动（多选标签）/ 手动指定（下拉） | — |
| 输入说明 | 文本 | 声明读取工作区哪些路径 |
| 输出约定 | 文本 | 声明写入路径/产物 |
| **上下文与收敛**（分组，R4 采纳） | — | 见 6.7 |

### 6.3 评审/校验节点
评审专家（下拉，提示「独立否决视角」）、评审要点（多行）、**回退目标节点**（下拉，仅前序节点，唯一必填）、通过说明、不通过说明。

### 6.4 人工确认节点
确认事项说明、方案模板路径（workspace 路径）、超时策略（不超时 / 超时提醒 / 超时自动终止 + 时长）。

### 6.5 fan-out 网关
任务清单来源（上游节点 + 产物路径）、分片规则（按清单项 / 自定义表达式 + 示例）、并发上限（数字，默认 50）、子任务模板（专家 + Skill + 独立 worktree 开关）。

### 6.6 fan-in 网关
聚合策略（单选：全部完成 / 失败阈值[百分比输入] / 抽样人工审核[抽样数]）、汇聚产物写入路径。

### 6.7 「上下文与收敛」分组（专家/评审节点通用）
| 配置 | 控件 | 说明 |
|---|---|---|
| 知识索引注入 | 级联多选：业务域→价值流→场景→代码入口 + SVO 锚点输入 | 防大海捞针 |
| 收敛约束 | 格式规范（文本）、上下文上限（数字，token） | 仅配置展示 |
| 工具使用权限 | 从工具库勾选 chips | 引用「工具与集成」页资产 |

## 7 校验规则

孤立节点、缺少开始/结束、评审节点缺回退目标、fan-out 缺清单来源、专家节点未绑定专家、多出边冲突；错误面板点击定位。

## 8 关键交互流程

新建（列表进入）→ 拖入节点 → 连线 → 逐节点配置 → 校验通过 → 保存 → 发布 → 运行（跳转实例详情）。

## 9 模拟数据依赖

`MOCK.workflows[i].graph`：`{nodes:[{id,type,name,expertId,config}], edges:[{from,to,kind:'seq'|'rollback'|'parallel'}], stages:[...]}`——该结构即 DSL 视图内容。
