# 效能看板

> 导航：运行与运营 / 效能看板　|　形态：轻量仪表盘　|　前置：`design/components/ui-shell/spec.md`

## 1 页面定位

量化智能体流程交付价值与运行健康（R3 采纳轻量版）：KPI 指标卡 + 趋势图 + 准出记录汇总 + Skill 审计。

## 2 布局结构

```
┌──────────────────────────────────────────────────────────────────┐
│ 效能看板                          时间范围[近8周▾]  更新于 10:15    │
├──────────────────────────────────────────────────────────────────┤
│ [需求吞吐率 12/周 ↗] [现场缺陷率 0.8% ↘] [成功率92%·均时1.8h]       │
│ [待人工确认 1 →]     [并行子任务 52,310·失败率2.1%]                │
├───────────────────────────────────────┬──────────────────────────┤
│ 趋势图（近8周）                         │ 阶段准出通过率             │
│  吞吐率线 ──╱──╲──╱──                  │ 需求分析  ▓▓▓▓▓▓░ 86%    │
│  缺陷率线 ──╲──╱──╲──                  │ 方案设计  ▓▓▓▓▓░░ 78%    │
│                                       │ 开发测试  ▓▓▓▓░░░ 64%    │
```

## 3 元素明细

| 区域 | 元素 | 类型 | 说明与交互 |
|---|---|---|---|
| 头部 | 时间范围下拉 | select | 近 4 周 / 8 周（默认）/ 12 周；显示数据更新时间 |
| 指标卡 ×5（R4） | 需求吞吐率 | 卡+迷你趋势线 | 需求/周 + 环比箭头（PPT P2 核心指标） |
| | 现场缺陷率 | 卡+迷你趋势线 | 百分比 + 环比 |
| | 实例成功率与平均耗时 | 双值卡 | — |
| | 待人工确认数 | 数字卡 | 点击跳实例列表「等待人工确认」Tab |
| | 并行子任务规模 | 双值卡 | 累计总量 + 失败率 |
| 趋势图 | 吞吐率/缺陷率双线 | SVG 手绘 | 横轴周，含悬浮数值提示（原型静态提示） |
| 准出通过率 | 四阶段横向条形 | SVG | 对应 P1 四阶段评审准出 |
| 准出记录汇总表 | 列：时间/实例/阶段/评审节点/结论标签/意见摘要 | 表格分页 | 实例 ID 可跳实例详情；数据来自实例评审节点结果汇总（R3 开放点 3：非打分卡配置） |
| Skill 审计列表 | 列：技能名/问题类型标签（被跳过/自我冲突/老化）/发生次数/最近发生/建议操作 | 列表卡 | 建议操作「查看 Skill」跳 Skill 库详情；数据模拟 P3/P4 技能老化治理诉求 |

## 4 状态与空态

- 数据不足（<2 周）时趋势图显示提示「数据积累中」
- 审计列表为空：空态「暂未发现技能规则异常」

## 5 模拟数据依赖

`MOCK.analytics`：`{kpi:{throughput[],defectRate[],successRate,avgDuration,pendingConfirm,subtaskTotal,subtaskFailRate},stagePassRate{...},reviewRecords[],skillAudit[]}`（近 8 周序列，审计条目 6 条）。
