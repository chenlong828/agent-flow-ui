# 效能看板

> 导航：运行与运营 / 效能看板　|　形态：轻量仪表盘　|　前置：`design/components/ui-shell/spec.md`

## 0 模块卡

> 追溯：`REQ-0009` / `SCN-0009`（designed，未 verified）。

- 状态：active
- 单元 / 层：组件 / L2 页面组件
- 业务价值：为管理者提供交付吞吐、缺陷率、阶段准出与 Skill 审计的只读回看；没有它，运行数据只能停在实例列表，无法回答「整体是否变好、卡在哪个阶段」。
- 负责 / 不负责：负责 KPI 指标卡、吞吐/缺陷率趋势、阶段准出率、评审准出记录汇总与 Skill 审计列表的只读渲染；不负责实例原始轨迹与控制（`CMP-instances`）、Skill 的定义与启停（`CMP-skills`）、指标口径的采集与计算（原型为夹具）。
- 数据所有权：只读 `MOCK.analytics`（`weeks/throughput/defectRate/successRate/avgDurationS/pendingConfirm/subtaskTotal/subtaskFailRate/stagePass/reviewRecords/skillAudit`）；不写任何 MOCK 集合，不写 localStorage/sessionStorage。
- 公开契约：页面入口 `pages/analytics.html`；操作 `CMP-analytics#overview`、`#trend`、`#stage-pass`、`#review-records`、`#skill-audit`；不变量 所有数字与 `MOCK.analytics` 同源，页面不做二次业务计算；趋势默认近 8 周、可切近 4 周（近 12 周禁用，标注「数据积累中」）；阶段准出固定 4 个阶段；评审记录按夹具顺序（新→旧）分页展示，页面不重排；审计条目只读，不提供修复按钮。
- 依赖：`DF`（外壳、统计卡、表格、Tabs、图标）/ `MOCK`；不依赖其他页面组件。
- 变化轴：指标口径与数据来源（当前为夹具，接真实运行数据时最易变），新增指标须同时改卡片、趋势与空态。
- 验证入口：`npm start` + `/pages/analytics.html`；`node tools/smoke-test.js`（12 页冒烟，含本页）；SCN-0009（designed，3 正 1 反测试方案已登记；runner 待补）。
- 预算：`analytics.js` 约 8 KB + 本规格约 4 KB，无专属测试；上限 120k token，远低于上限。
- 单独运行：`npm start` → `/pages/analytics.html`（全部数据来自 `MOCK.analytics`，无跨页依赖）。
- 删除测试：删除后失去唯一的跨实例经营回看入口，指标会散落到实例页；但无业务写入，删除只影响可视化，故保留为独立只读组件。
- 已知偏差：M1 追溯已补（REQ-0009/SCN-0009），场景 designed、未 verified；仅冒烟；指标与记录均为模拟数据；准出汇总按「评审结果记录」呈现，不是 50 项打分卡配置（OQ-3）。

## 1 页面定位

量化智能体流程交付价值与运行健康（R3 采纳轻量版）：KPI 指标卡 + 趋势图 + 准出记录汇总 + Skill 审计。

## 3 元素明细

| 区域 | 元素 | 类型 | 说明与交互 |
|---|---|---|---|
| 头部 | 时间范围下拉 | select | 近 4 周 / 8 周（默认）/ 12 周；显示数据更新时间 |
| 指标卡 ×5（R4） | 需求吞吐率 | 卡+迷你趋势线 | 需求/周 + 环比箭头（PPT P2 核心指标） |
| | 现场缺陷率 | 卡+迷你趋势线 | 百分比 + 环比 |
| | 实例成功率与平均耗时 | 双值卡 | — |
| | 待人工确认数 | 数字卡 | 点击跳实例列表「等待人工确认」Tab |
| | 并行子任务规模 | 双值卡 | 累计总量 + 失败率 |
| 趋势图 | 吞吐率/缺陷率双线 | SVG 手绘 | 横轴周，含悬浮数值提示（原型静态提示） |
| 准出通过率 | 四阶段横向条形 | SVG | 对应 P1 四阶段评审准出 |
| 准出记录汇总表 | 列：时间/实例/阶段/评审节点/结论标签/意见摘要 | 表格分页 | 实例 ID 可跳实例详情；数据来自实例评审节点结果汇总（R3 开放点 3：非打分卡配置） |
| Skill 审计列表 | 列：技能名/问题类型标签（被跳过/自我冲突/老化）/发生次数/最近发生/建议操作 | 列表卡 | 建议操作「查看 Skill」跳 Skill 库详情；数据模拟 P3/P4 技能老化治理诉求 |

## 4 状态与空态

- 数据不足（<2 周）时趋势图显示提示「数据积累中」
- 审计列表为空：空态「暂未发现技能规则异常」

## 5 模拟数据依赖

`MOCK.analytics`：`{kpi:{throughput[],defectRate[],successRate,avgDuration,pendingConfirm,subtaskTotal,subtaskFailRate},stagePassRate{...},reviewRecords[],skillAudit[]}`（近 8 周序列，审计条目 6 条）。
