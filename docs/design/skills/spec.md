# Skill 库

> 导航：资产与注册 / Skill 库　|　形态：列表 + 详情抽屉　|　前置：`design/ui-shell.md`

## 1 页面定位

独立 Skill 资产库（R2 确认）：沉淀可复用能力单元，供专家组合引用；结构遵循 PPT P8 的 Skill 规范（描述路由 / 工作内容渐进披露 / 踩坑禁令 / 参考引用 / 版本）。

## 2 布局结构

```
┌────────────┬───────────────────────────────────────────────────┐
│ 筛选栏      │ Skill 库                        [🔍搜索] [+ 新建Skill]│
│ ─ 分类     ├───────────────────────────────────────────────────┤
│  全部(12)  │ 名称      类别    常驻摘要       引用 版本 状态 操作 │
│  编码(4)   │ CRES技能  编码    遵循CRES框架…   3   v1.4 启用 ⋮   │
│  测试(3)   │ 调用链分析 检索    定位符号引用链…  5   v2.1 启用 ⋮   │
│  审视(3)   │ AB交叉审视 审视    独立否决视角…   4   v1.0 启用 ⋮   │
│  检索(2)   │ …                                                 │
│ ─ 标签     │                                                   │
│ [CRES][LDP]│                                                   │
└────────────┴───────────────────────────────────────────────────┘
          选中行 → 右侧详情抽屉（720px）↓↓
```

## 3 元素明细

| 区域 | 元素 | 类型 | 说明与交互 |
|---|---|---|---|
| 左筛选 | 分类树 | 树 | 编码 / 测试 / 审视 / 检索 / 造数工具 / 其他，含计数 |
| 左筛选 | 标签 | chips 多选 | 如 CRES、LDP、SVO |
| 主区 | 搜索框 | 输入 | 名称/关键词匹配 |
| 表格 | 名称、类别标签 | — | 名称点击打开详情抽屉 |
| 表格 | 常驻摘要 | 文字截断 | 「常驻 Context 的短描述」预览 |
| 表格 | 触发关键词 | chips（前 3） | — |
| 表格 | 被引用数 | 数字链接 | 点击弹层列出引用该 Skill 的专家/工作流节点 |
| 表格 | 版本 / 状态 / 更新时间 | — | 状态：启用/停用（开关） |
| 表格 | 操作 | ⋮ 菜单 | 查看/编辑、停用、删除（被引用时禁删并提示） |

## 4 详情抽屉（查看/编辑复用，编辑态表单化）

| 区块 | 内容 | 交互 |
|---|---|---|
| ① 描述与路由 | **常驻摘要**（textarea，≤200 字，提示「常驻 Context」）、能力清单、触发上下文场景、触发关键词 chips | 渐进式披露第一层：短小精干 |
| ② 工作内容（渐进披露） | 折叠章节列表：工作流程总述目录 → 详细步骤/约束 → 参考案例模板 → 外部脚本使用指南 → 完成验证方案 | 每章节 Markdown 编辑 + 折叠展开；标注「按需加载」 |
| ③ 踩坑记录与禁令 | 红色警示区列表（严格禁止的操作） | 增删行；置顶显示 |
| ④ 参考引用 | 关联 Skill chips（跳转）、示例/模板文件、外部规范链接 | — |
| ⑤ 版本历史 | 列表：版本/时间/变更说明/更新人 | 只读 |

## 5 关键交互流程

新建（弹窗：名称/类别/常驻摘要）→ 详情抽屉补全五区 → 保存（版本 +0.1）→ 停用（提示被引用影响）。

## 6 状态与空态

- 库为空：空态「沉淀第一个 Skill」
- 分类无数据：显示空分组（计数 0）

## 7 模拟数据依赖

`MOCK.skills[]`：12 条，字段 `{id,name,category,tags,summary,triggers,sections{overview,steps,examples,scripts,verification},pitfalls[],refs[],version,enabled,updatedAt,usedBy}`（覆盖 CRES、LDP、调用链分析、元数据查询、SVO 拆分、AB 交叉审视、业务功能树检索、Linter/DSL 检索、契约断言、业务造数等）。
