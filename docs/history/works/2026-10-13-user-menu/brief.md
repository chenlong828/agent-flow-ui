# 工序：顶栏用户区改「陈龙」＋下拉菜单（含退出登录）

## 需求（领取 OQ-7）

> 引登记表口径原文：顶栏右上角用户区域：显示名改为「陈龙」；点击弹出下拉菜单（含退出登录）。
> 可验收口径：全部页面右上角均显示「陈龙」；点击弹出菜单、点击他处收起；「个人 Key 管理」跳 Key 页，
> 「退出登录」有确认与反馈（原型静态）。

## 背景

- `renderShell` 当前用户区是静态 span（`<span class="user">陈明 ▾</span>`），有下拉箭头但无任何菜单；
- `design/components/ui-shell/spec.md` §2 元素明细早已约定：用户头像+名称为下拉，菜单 = 个人 Key 管理（快捷入口）/ 退出登录（原型静态）——本工序把约定落成实现；
- 主色样式、`.menu`（fixed，z-index 250）与 `DF.menu(items, x, y)` 均已存在（编辑器右键菜单在用），按《代码重构要点》§4 复用共享能力，不另起炉灶。

## 验收标准

- [ ] 全部 12 页右上角显示「陈龙」（引擎层循环断言）；
- [ ] 点击用户区弹出菜单：含「个人 Key 管理」「退出登录」两项；
- [ ] 点击菜单外任意处菜单收起；再点用户区可再次弹出；
- [ ] 点「个人 Key 管理」跳转 keys.html；
- [ ] 点「退出登录」弹出确认框，确认后 Toast 反馈，取消无副作用（原型静态，无真实登录态）;
- [ ] 菜单在默认字号与「最大」字号（transform 兜底缩放路径）下均弹出在用户区正下方、不被遮挡（命中测试 + 位置断言）。

## 影响面

- design/：`design/components/ui-shell/spec.md` §2（用户区交互描述落成现行行为）
- 代码：`assets/js/ui.js`（renderShell 用户区 + 菜单绑定；新增 logout 图标）
- 不改：`assets/js/mock-data.js` 中业务数据里的「陈明」字段（模拟数据人物，非登录用户名，不当顺手修）
