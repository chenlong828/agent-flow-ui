# 需求裁定记录（R1–R4 问答决策）

> 来源：原《01-需求归纳总结》第 10 节及附录。活结论已蒸馏进 design/ 各规格，本件为裁定过程存档。

## 10. 问答决策记录

| 轮次 | 问题 | 结论 |
|---|---|---|
| R1 | 原型形态 | 高保真交互 HTML 原型（纯前端 + 模拟数据） |
| R1 | 节点类型 | 五类全选：专家执行、评审/校验、人工确认、fan-out/fan-in 网关、开始/结束与阶段分组 |
| R1 | 回退语义 | 固定单一回退点（预设唯一回退目标，失败即回退） |
| R1 | 并行调度 | 清单驱动 + 聚合策略 + 数千规模聚合视图 |
| R1 | 实例控制 | 异常终止/暂停恢复、节点重试/从指定节点重跑、留痕查看（方案确认由人工确认节点承载；不做人工注入回退） |
| R2 | 方案确认承载 | 人工确认节点承载，实例详情页批准/驳回，列表角标提示 |
| R2 | Skill 管理边界 | 独立 Skill 库页，专家组合引用 |
| R2 | Harness 覆盖 | 基础登记、能力标签与调度绑定、心跳与健康、并发上限与配额（全选） |
| R2 | 工作区覆盖 | 仓库绑定与分支策略、目录结构模板、凭证关联、清理归档（全选） |
| R2 | Key 覆盖 | git ssh-key、LLM API Key、掩码与有效性校验、按用途绑定（全选） |
| R2 | 视觉风格 | 浅色企业后台，中文界面 |
| R3 | 新增节点（Google 建议） | **全部不采纳**：意图路由、Re-act 循环由专家节点 + 流程配置扮演；CI/CD 节点暂不做；当前以演示跑通核心模型为优先 |
| R3 | 工具注册归属 | 新增独立「工具与集成」页（MCP/CLI 注册表；CI/CD 绑定仅占位） |
| R3 | 效能看板 | 采纳轻量看板页（指标卡 + 准出记录汇总 + Skill 审计） |
| R3 | 波谷调度 | 不表现（文档记录机制即可） |
| R3 | 节点上下文配置 | 采纳：知识索引注入、收敛约束与上下文上限、工具使用权限（未选准出打分卡） |
| R3 | DSL 视图 | 编辑器增加只读 DSL（JSON/YAML）预览标签 |
| R4 | 实例轨迹呈现 | 只读流程图（复用画布渲染，状态着色 + 回退弧线） |
| R4 | 详情形态策略 | 抽屉为主（专家/Skill/Harness/工具/子任务）；实例详情、工作区详情用独立二级页 |
| R4 | DSL 视图位置 | 顶栏「画布 / DSL」Tab 平级切换 |
| R4 | 发起运行参数 | 工作流（已发布）+ 工作区 + 备注 |
| R4 | fan-out 子任务 | 聚合统计 + 抽样明细 50 条 + 单条子任务详情抽屉 |
| R4 | 看板指标卡 | 吞吐率、现场缺陷率、成功率与平均耗时、待人工确认数、并行子任务规模（未选 Skill 健康度卡，审计列表保留） |
| R4 | 版本管理 | 版本号 + 草稿/已发布标记（无版本历史） |
| R4 | 交付形式 | 页面细化按「每页面一个文档」输出至 docs/（02~12 号文档） |

### 附：Google 建议 vs 本方案裁定对照（存档）

| Google 建议 | 裁定 |
|---|---|
| Re-act 循环节点、意图路由节点、CI/CD 触发节点 | 不设专门节点，由专家节点 + 流程配置扮演（R3） |
| Fan-out/Fan-in、人工校准门禁、固化专家模板、Skill 渐进披露 | 已在方案内（一致） |
| SVO 分层知识索引注入、收敛约束、工具权限 → 节点配置 | 采纳为节点「上下文与收敛」配置分组（R3） |
| MCP/CLI 工具注册独立 Studio | 采纳为「工具与集成」页（R3） |
| 效能运营与质量治理看板 | 采纳轻量版（R3） |
| 波谷跑批调度日历 | 不表现（R3） |
| DSL/Code 双向编辑器 | 只读 DSL 视图（R3） |
| Skill 自动更新闭环、50+ 项打分引擎、上下文实时裁剪引擎 | 引擎级逻辑不实现；原型仅展示"反馈回写"入口、审计条目与配置项 |
| 5 大页拆分（未含 Harness 注册、Key 管理、工作流列表） | 保留原始需求页面；扩展为 4 组 10 页导航 |
